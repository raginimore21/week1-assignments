# Task 3: CSS Challenge

## Overview
This project demonstrates practical CSS skills through three exercises: Flexbox layout, CSS Grid layout, and CSS animations.

## Exercises

### 1. Flexbox Layout
- Created three responsive testimonial cards.
- Used `display: flex`, `justify-content`, `align-items`, `gap`, and flexible widths.
- Added hover effects using `transform` and `transition`.
- Stacked the cards vertically on mobile devices.

### 2. Grid Layout
- Created a gallery of six technology cards.
- Used `display: grid` and `repeat()` for responsive columns.
- Maintained consistent spacing and card styling.
- Changed from three columns on desktop to two on tablet and one on mobile.

### 3. Animation
- Added a smooth button hover and click interaction.
- Created a rotating loading spinner using `@keyframes`.
- Included reduced-motion accessibility support.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` — Website structure
- `style.css` — Layout, styling, responsiveness, and animation
- `script.js` — Button interaction
- `screenshots/` — Assignment screenshots

## How to Run

2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use Live Server.
