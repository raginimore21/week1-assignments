
# Green Chilli Restaurant – Responsive Landing Page

## About the Project

Green Chilli is a responsive restaurant landing page created as part of my internship assignment. The website presents popular food items and provides information about the restaurant in a simple and user-friendly design.

## Features

- Responsive navigation bar with a mobile hamburger menu
- Home section with a food background image
- Popular menu section with food images and descriptions
- About section introducing the restaurant
- Contact form with input validation
- Responsive layout for desktop and mobile devices
- Footer with automatically updated copyright year

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, Flexbox, and media queries
- **JavaScript** – Mobile navigation, form feedback, and current year
- **Unsplash** – Food images used in the website

## How to Run the Project

1. Download or clone this repository.
2. Open the `business-landing-page` folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Resize the browser or enable mobile device mode to test responsiveness.

## Responsive Design

The website uses CSS media queries to adapt its layout to smaller screens. On mobile devices, the navigation menu can be opened using the hamburger button, and menu cards are arranged vertically for easier viewing.

## Image Credits

Food images are loaded from Unsplash using image URLs. Image sources and applicable usage terms should be checked before using them.

## Contact Form

The contact form includes HTML validation and JavaScript feedback. It is a front-end demonstration and does not currently send messages to a server or email address.
