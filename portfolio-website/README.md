# Ragini More - Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, educational background, and contact information as a Computer Engineering graduate interested in Full Stack Development.

## About Me

I am Ragini More, a Computer Engineering graduate from Sanjivani College of Engineering, Kopargaon. I am passionate about web development, software development, and building responsive, user-friendly web applications.

## Features

- **Home:** Introduction and professional role.
- **About Me:** Educational background, interests, and career goals.
- **Skills:** Technology logos and skill cards.
- **Projects:** Showcase of academic and development projects.
- **Contact:** Email, GitHub, LinkedIn, and a contact form.
- **Responsive Design:** Layout adjustments for desktop, tablet, and mobile screens.
- **Interactive Elements:** Navigation links, hover effects, and contact form feedback.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the profile photo is saved as `assets/ragini.jpg`.
4. Open `index.html` in a web browser.
5. Alternatively, install the Live Server extension in VS Code and click **Go Live**.
