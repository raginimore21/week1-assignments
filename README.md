# Task 1-Personal Portfolio Website


## About the Project

This is my personal portfolio website, developed to showcase my profile, educational background, technical skills, projects, and contact information. The website has a clean and professional design with an orange-and-black color theme and a responsive layout.

## Objectives

- Present my profile and educational background.
- Showcase my technical skills and technologies.
- Display my academic and development projects.
- Provide contact information and a contact form.
- Practice HTML, CSS, and JavaScript development.

## Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, animations, and responsive design.
- **JavaScript** — Contact form validation and interactive functionality.
- **Git and GitHub** — Version control and project hosting.

## Website Pages

### 1. Home
Introduces me with my name, profile photo, and a short professional introduction.

### 2. About
Provides information about my background, education, and career objective.

### 3. Skills
Displays my technical skills using technology logos and skill cards, including HTML5, CSS3, JavaScript, React.js, Java, MySQL, Node.js, and Git & GitHub.

### 4. Projects
Showcases three projects:

- **AI PDF Q&A System:** An application for asking questions about uploaded PDF documents.
- **Kitchen to Community:** An AI-enabled platform focused on food donation and waste reduction.
- **Parallel Text Classification:** A text classification project using the Naive Bayes algorithm and C++ OpenMP.

### 5. Contact
Provides my email, social profile links, and a contact form.

## Features

- Five separate HTML pages.
- Consistent navigation across all pages.
- Responsive design for desktop, tablet, and mobile.
- Orange-and-black visual theme.
- Technology logos and interactive skill cards.
- Project cards with hover effects.
- Contact form with JavaScript validation.
- Semantic HTML and accessible form labels.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML files, `style.css`, `script.js`, and the `assets` folder are present.
4. Open `index.html` in your web browser.
5. Use the navigation menu to visit Home, About, Skills, Projects, and Contact.

No additional installation is required for the basic website.

# Task-2 :Green Chilli Restaurant – Responsive Landing Page

## About the Project

Green Chilli is a responsive restaurant landing page created as part of my internship assignment. The website presents popular food items and provides information about the restaurant in a simple and user-friendly design.

## Features

- Responsive navigation bar with a mobile hamburger menu
- Home section with a food background image
- Popular menu section with food images and descriptions
- About section introducing the restaurant
- Contact form with input validation
- Responsive layout for desktop and mobile devices
- Footer with automatically updated copyright year

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, Flexbox, and media queries
- **JavaScript** – Mobile navigation, form feedback, and current year
- **Unsplash** – Food images used in the website

## Project Structure

```text
business-landing-page/
├── index.html
├── style.css
├── script.js
├── screenshots/
│   ├── landing-page.png
│   ├── mobile-hero.png
│   ├── services-section.png
│   └── contact-form.png
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the `business-landing-page` folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Resize the browser or enable mobile device mode to test responsiveness.

## Responsive Design

The website uses CSS media queries to adapt its layout to smaller screens. On mobile devices, the navigation menu can be opened using the hamburger button, and menu cards are arranged vertically for easier viewing.

## Image Credits

Food images are loaded from Unsplash using image URLs. Image sources and applicable usage terms should be checked before using them.

## Contact Form

The contact form includes HTML validation and JavaScript feedback. It is a front-end demonstration and does not currently send messages to a server or email address.
