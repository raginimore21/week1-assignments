# Task 1-Personal Portfolio Website

## Objective
The objective of this project is to develop a responsive personal portfolio website to showcase my educational background, technical skills, projects, and contact information. It helps present my profile professionally and allows recruiters to learn about my experience and work.

## Features

- **Home:** Introduction and professional role.
- **About Me:** Educational background, interests, and career goals.
- **Skills:** Technology logos and skill cards.
- **Projects:** Showcase of academic and development projects.
- **Contact:** Email, GitHub, LinkedIn, and a contact form.
- **Responsive Design:** Layout adjustments for desktop, tablet, and mobile screens.
- **Interactive Elements:** Navigation links, hover effects, and contact form feedback.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Devicon logos for technology icons

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the profile photo is saved as `assets/ragini.jpg`.
4. Open `index.html` in a web browser.
5. Alternatively, install the Live Server extension in VS Code and click **Go Live**.
